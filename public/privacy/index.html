Privacy

This page describes the site as built. It is not a claim that a particular host has already turned on every optional store.

Page views

HTML pages send the path to /count. The counter stores that path and a coarse human/bot class from the user agent. It does not set a cookie and it does not store your address. Totals are public at /stats and /count.

Calculator feedback

If you choose yes or no, a receipt stores the time, the tool name, the vote, an optional comment of at most 256 characters, and a snapshot of the calculation. Comments and fields that look like an email, phone number, or long account number are refused. Receipts are not public. Export requires a private token.

JPEG uploads

Only a JPEG of a written invoice, estimate, or offer is in scope. You must confirm that, and confirm you removed names, addresses, phone numbers, account numbers, signatures, and barcodes. The server checks that the file is a JPEG inside size and shape limits. It does not OCR the picture and does not claim to know that the picture is an invoice beyond your confirmation. Files are private. They are not published because a box was checked.

Contact messages

The about form stores the message you type and a reply address if you offer one. That record is private.

Cookies and other analytics

No third-party advertising or analytics script is included. Adding one later would be a separate decision, with consent.

Deletion

Ask on the contact form with the topic Privacy or deletion, and include the receipt id if you have one. Removal depends on the operator being able to read the private store.
